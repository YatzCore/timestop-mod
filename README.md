# Ultimate Time Stop

A Minecraft mod for 1.20.1 that allows you to stop, slow down, and manipulate time using pocket watches.

## Features

### Modes
- **Time Stop**: Freezes all mobs, projectiles, fluids, and world time. You can walk on water and lava. Damage dealt to mobs accumulates and discharges when time resumes.
- **Slow Motion**: Slows down the entire world to 25% speed for a smooth bullet-time effect.
- **Matrix**: The world runs in slow motion, but you move, attack, and use items at normal speed.
- **Fast Forward**: Speeds up the entire world (movement, smelting, day/night cycle) by 5x.

### Watches
- **Chronos Pocket Watch (Survival)**: Lasts 10 seconds with a 15-second cooldown after time resumes.
- **Infinite Chronos Watch (Creative)**: Unlimited duration and no cooldown.

## Controls

- **Right-Click** (holding watch): Start or stop the selected mode.
- **Shift + Right-Click** (holding watch): Switch between modes without activating.
- **V**: Toggle the active mode on or off.

## Crafting Recipe

The Chronos Pocket Watch can be crafted in survival on a crafting table:

- **1x Clock** (center)
- **3x Amethyst Shard** (top, left, right)
- **1x Echo Shard** (bottom)

## Installation

1. Install **Minecraft 1.20.1** with **Forge** or **NeoForge** (47.1.0 or higher).
2. Download the latest `.jar` file from [Releases](https://github.com/YatzCore/timestop-mod/releases).
3. Place the `.jar` into your `.minecraft/mods` folder.
