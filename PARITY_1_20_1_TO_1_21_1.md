# Minecraft 1.20.1 → 1.21.1 feature comparison — 1.8.0

Compared the working 1.20.1 release **1.8.0** with the existing 1.21.1 **1.6.6** source tree.
The result supports **Fabric, Forge and NeoForge** on Minecraft 1.21.1 / Java 21.
The existing 1.21.1 Sable, TaCZ and accessory work is retained. The 1.20.1 release is unchanged by this port.

Initial source inventory found 35 absent Java classes, 30 shared files changed since the pre-Prediction reference,
119 byte-identical files, and 213 files requiring comparison with native APIs or newer 1.21.1 work.
Every missing feature was either implemented or replaced by its native 1.21.1 API. No 1.20.1 resource files were absent.

## Native adaptations

- Potion and charged-crossbow data use native data components. Effect holders and undead tags replace removed APIs.
- Projectile gravity and step height use native accessors/attributes. Fireball acceleration uses its current vector and acceleration power.
- Riptide preview checks read enchantment effect components without evaluating RNG-based enchantment strength.
- Modern vertex consumers, mesh builders and partial-tick APIs replace the old rendering interfaces.
- Server wake scheduling preserves native nanosecond clocks. Existing native Fast Forward and Sable handling remain in place.
- Raycasts keep native Sable/modded collision hooks and the loaded-terrain guards.
- Loot-container rewind uses the public native loot-table accessor; native DeltaTracker handles the client clock. Old accessors/mixins with the same purpose are not duplicated.
- Existing mode ordinals 0–6 are preserved. Prediction is 7, Combat Slow is 8, Self Acceleration is 9.
- Forge uses protocol **5**. NeoForge uses payload version **1.8.0-prediction-variants**. Match client/server builds; no old-network compatibility is claimed.

## Controls

J or Shift + right-click opens a watch. V activates it. Prediction unlocks on Netherite/Creative watches.
The existing Slow Motion / Fast Forward cards have a <> selector; click it, right-click the card,
or use Shift + its number to select Combat Slow / Self Acceleration. No extra mode panels are added.
H → Visuals & FX → **Swim in stopped time** controls the server-wide frozen-liquid collision setting.

```text
/timestop start prediction [seconds]
/timestop start combatslow [seconds]
/timestop start selfacceleration [seconds]
/timestop speed prediction 0.25
/timestop speed slowmotion 0.25
/timestop speed fastforward 5
/timestop rewind speed 2
/timestop speed rewind 2
```

## Limits and compatibility boundaries

Mob routes show current navigation/motion, not future AI decisions. Enderman destinations appear after native selection.
Arcs use currently loaded geometry; moving Sable terrain is not advanced into a speculative future physics world.
Shot spread, recoil, attachments, custom renderers, unknown ammunition and modded application callbacks can change results.
No chunks are generated or live entities ticked for forecasts. Unknown explosives and fireworks receive no invented blast area;
Riptide tridents and crossbow fireworks have no held-shot preview. TNT stops at unsupported callback terrain.
Explosion cues show potential exposure rather than guaranteed damage, kills or destroyed blocks.

The same clutter ceilings apply: 12 paths, eight projectile silhouettes, 12 body silhouettes and two effect areas.
See [Prediction](PREDICTION.md) and [time variants](TIME_VARIANTS.md) for detailed behavior.
The earlier [TaCZ acceptance limits](integration/readiness/TACZ_PARITY.md) still apply: automated checks do not establish
all third-party packs, complete reload/bolt cycles, every multiplayer ability combination, or subjective audio quality.
No existing world is converted or opened by the test fixtures.

## Validation

- Shared Fabric suite: **162/162** passed; shared JUnit checks: **5/5**.
- Native Forge and NeoForge parity suites: **44/44 each**, including fractional/batched rewind depth and cancellation.
- Native TaCZ suites: **31/31 on each loader**, including held-gun read-only profiles and actual bullet movement in Prediction, Combat Slow and Self Acceleration.
- Combined stock Sable/vanilla review suite: **220/220**, including body rates, ownership/dependency/rewind handling and all shared regressions.
- NeoForge Sable/Create landing suite: **2/2 tests**, covering **30 landing cases** across the original and new modes plus the independent tilted-body/rotation check.
- All three client scenes passed moving aim, bounded holograms, distant untracked arrows, intercepts, enemy pre-release shots, catch/redirect, day/night potion/cloud/hazard cues and cleanup. Actual movement measured 4.05758 blocks normally and 20.28791 with Self Acceleration over the same input period. Stopped-water swimming and setting synchronization passed.
- All three production jars passed packaged client startup and native TaCZ firing/feedback checks. No test/baseline classes are present in the distributed jars.

The installed Fabric 0.19.5/Sodium/Trinkets and NeoForge 21.1.250/Sable/Create/Curios/JEI profile dependencies also passed isolated packaged client checks.
The jars, hashes, logs, screenshots and installation backups are listed in the release folder. Installed-profile loader checks and exact package hashes are recorded there separately.
